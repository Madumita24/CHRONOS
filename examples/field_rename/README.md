This is the generalized-engine replay of the immutable golden scenario:
`order_total -> order_amount` in the certified PostgreSQL `orders` dataset.
Both fields and the lineage originate from the frozen DataHub-derived snapshot.
The proposal has a separate generalized analysis ID; it does not replace or
masquerade as the Phase 4 certification for `CHRONOS-DEMO-001`.

Run it with the command in `PHASE_6_1_DEVELOPER_GUIDE.md`.
